📐 Mathematical Standards & Conventions

1. Representation of Complex Numbers: A complex number is represented as $z = a + bi$, where $a = \text{Re}(z) \in \mathbb{R}$ is the real part, $b = \text{Im}(z) \in \mathbb{R}$ is the imaginary part, and $i$ satisfies the fundamental algebraic identity $i^2 = -1$.

2. Principal Argument Convention: The principal argument $\text{Arg}(z)$ is chosen within the standard mathematical interval $(-\pi, \pi]$ radians (equivalent to $(-180^\circ, 180^\circ]$). For the zero complex number $z = 0 + 0i$, the modulus $|z| = 0$ is defined, but the argument is mathematically undefined.

3. Roots and Branch Cuts: Every nonzero complex number $z = r e^{i\theta}$ has exactly $n$ distinct $n$-th roots: $$w_k = r^{1/n} \exp\left(i \frac{\theta + 2k\pi}{n}\right), \quad k = 0, 1, \dots, n-1$$ The principal $n$-th root corresponds to $k = 0$.

4. Multiplicative Inverse: The reciprocal $z^{-1} = 1/z$ exists for all $z \in \mathbb{C} \setminus \{0\}$ and satisfies the identity $z \cdot z^{-1} = 1$. Division by the zero complex number is strictly rejected with a clear mathematical error.

⚙️ Architecture & Security

Zero eval() Policy: ComplexLab rejects arbitrary code execution. All mathematical expressions are parsed using Python's Abstract Syntax Tree (AST) compiler with a strict whitelist of arithmetic operations, numbers, and constants ($i, j, \pi, e$).

High-DPI Vector Canvas: The interactive complex plane is rendered natively using the HTML5 Canvas API with Retina device pixel ratio scaling, eliminating external rendering latency and delivering smooth real-time drag, pan, and zoom operations.

Client-Side Privacy: Calculation history and user theme preferences are stored exclusively inside your browser's localStorage. No personal data, tracking cookies, or external AI API keys are required.
